# Aurum Edge — اپ اندروید پایش بازار و معاملات کاغذی

[قرارداد فعلی V1 و محدودیت‌های اجرا](docs/CURRENT_CONTRACT_FA.md) مرجع واحد قوانین محصول است؛ توضیح نسخه‌های قدیمی نباید جایگزین آن شود. پروژهٔ بومی Kotlin / Jetpack Compose در `android/` قرار دارد. **هیچ سفارش واقعی به بروکر/صرافی ارسال نمی‌شود.**

## داده و تصمیم

- موتور واحد `SignalEngine`/`V1Scoring` چهار لایه را امتیازدهی می‌کند: ساختار EMA/ایچیموکو، RSI/MACD، پرایس‌اکشن حمایت/مقاومت و جهت/هم‌راستایی هفت تایم‌فریم `M1, M5, M15, M30, H1, H4, D1`. تنظیم ایچیموکوی این مسیر **۸/۲۴/۷۲، جابه‌جایی ۲۴** است؛ چارت تصویری TradingView منبع محاسبهٔ سیگنال نیست.
- هر یک از هفت بازه باید **۳۲۰ کندل بستهٔ واقعی** داشته باشد؛ درخواست زنده ۳۶۰ کندل است تا کندل در حال تشکیل حذف شود. نقص/کهنگی هر بازه موجب جهت نامعلوم و عدم ورود است؛ ۳۰۰۰ کندل شرط پایش زنده نیست. تاریخچهٔ عمیق‌تر فقط برای نمایش دورهٔ معاملهٔ ثبت‌شده کاربرد دارد.
- آستانهٔ قابل تنظیم **۶۰ تا ۹۵ از ۱۰۰**، پیش‌فرض ۸۵ است. امتیاز جزئی با «تأیید کامل» فرق دارد؛ مساوی شدن امتیاز دو جهت ورود را مسدود می‌کند. حالت‌های واقعی قابل تنظیم برای هر دسته `TREND / RANGE / HYBRID` هستند. نام‌های استراتژی و پروفایل‌های قدیمی صرفاً برای سازگاری دادهٔ ذخیره‌شده باقی مانده‌اند؛ فیلتر اجرایی/گزینهٔ مستقل نیستند.
- `MarketPlaybook` و خوانش پهنای بازار **زمینهٔ نمایشی/رتبه‌بندی** هستند، نه گیت اضافی یا موتور ورود موازی. اسکنر و نماد منتخب هر دو همان چهار لایه را ارزیابی می‌کنند؛ ورود کاغذی علاوه‌بر آن از تازگی فید، وتوی معتبر AI، محاسبهٔ بلیت، سقف ریسک و وضعیت بازار عبور می‌کند. خطای محاسبه، دادهٔ ناکافی و `NO_TRADE` علت‌های جدا دارند.
- سقف ریسک هر معامله ۰٫۵٪، زیان روزانه ۲٪، حداکثر چهار معاملهٔ باز و حداکثر دو معامله در هر دسته است؛ توقف پس از سه باخت متوالی و trailing طبق قرارداد V1 اجرا می‌شوند. پیش‌بینی سود یا سازگاری با هر فید برای هر نماد تضمین نشده است.

## صفحات

خانه، چارت TradingView، معامله/گزارش تصمیم، دیده‌بان، خبر، ژورنال معاملات کاغذی، بروزرسانی و تنظیمات. **صفحهٔ آموزش، بک‌تست، بازپخش آموزشی و کارت‌های آموزشی ژورنال حذف شده‌اند.** نمودار دورهٔ *معاملهٔ ثبت‌شده* در ژورنال یک نمایش از کندل‌های واقعی است، نه بک‌تست. فایل‌های قدیمی کاربر به‌صورت خودکار پاک یا به قیمت زنده تبدیل نمی‌شوند.

## ساخت و انتشار

پیش‌نیاز: JDK 17 و Android SDK 35 (build-tools 35.0.0).

```bash
cd android
./gradlew testDebugUnitTest lintDebug assembleDebug assembleRelease
```

ورک‌فلوی `.github/workflows/main.yml` آزمون، lint، ساخت و کنترل `applicationId`، SHA-256، گواهی امضا و افزایش `versionCode` را انجام می‌دهد؛ سپس در انتشار تأییدشده APK و متادیتا را در GitHub Release عمومی قرار می‌دهد تا بخش بروزرسانی اپ آن را پیدا کند. تطابق گواهی با Release عمومی، امضای APK نصب‌شدهٔ خاص یک گوشی را اثبات نمی‌کند. کلید امضا در مخزن نگهداری نمی‌شود.
