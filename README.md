# Aurum Edge

اپ اندروید بومی Kotlin / Jetpack Compose با سه تب اصلی:

- **خانه (`HomeScreen`):** وضعیت ساعت سشن بازار، بنر ۴ دسته دارایی، ترکینگ زنده معاملات باز و کارت آمار و مدیریت حساب.
- **چارت (`ChartScreen`):** چارت کامل TradingView با انتخابگر نماد و اندیکاتور ایچیموکو (`8/24/72`).
- **بروزرسانی (`UpdateScreen`):** بررسی، دانلود و نصب نسخهٔ جدید از داخل اپ با نمایش جداگانهٔ اثر انگشت گواهی نصب و کانال Release.

تمام تب‌های دیگر (معامله، دیده‌بان، ژورنال، تنظیمات، APIها)، موتورهای استراتژی قبلی، سرویس‌های پس‌زمینه و داده‌های ذخیره‌شدهٔ متد قبلی به‌طور کامل حذف شده‌اند.

## ساخت و آزمون

پیش‌نیاز: JDK 17 و Android SDK 35 (build-tools 35.0.0).

```bash
cd android
./gradlew testDebugUnitTest lintDebug assembleDebug assembleRelease
```
