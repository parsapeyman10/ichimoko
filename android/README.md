# اپ بومی اندروید — Trading

Kotlin + Jetpack Compose (بدون WebView). چارت/سیگنال/ژورنال/بک‌تست با دادهٔ خواندنی Twelve Data روی گوشی کار می‌کنند؛ دیده‌بان چندمنبعی جداست. **ارسال سفارش واقعی وجود ندارد.**

## قابلیت‌های قابل‌مشاهده

- «دیده‌بان»: BTC/ETH/XAU/AAPL/USD/IRT/طلای ۱۸، انتخاب منبع مستقل و قیمت نمایشی هر نماد، کلید *خواندنی* Twelve Data برای هر نماد، مقایسهٔ `CONFIRMED / CONFLICT / UNVERIFIED / NO_DATA`. فقط دو قیمت تازه و دارای زمان ارائه‌دهنده و با واحد یکسان تأیید می‌شوند؛ قیمت کش‌شده تأیید نیست.
- تاریخچهٔ قیمت‌های واقعاً دریافت‌شدهٔ هر منبع در SQLite روی گوشی و صفحه‌بندی در خود دیده‌بان؛ پاک‌سازی با تأیید در تنظیمات. تاریخچهٔ قبل از فعال‌سازی برنامه دانلود نمی‌شود.
- «اخبار فارسی» در دیده‌بان: نیازمند بک‌اند HTTPS و فید فارسی دارای مجوز؛ تحلیل قاعده‌ای و گیت توقف ورود *کاغذی* در صورت فعال‌سازی. در نبود فید وضعیت نامشخص و تیترها خالی‌اند.
- «یادگیری»: بک‌تست و walk-forward روی کندل واقعی Twelve Data؛ علاوه بر آن، **ورود CSV/TSV تاریخی MetaTrader از فایل گوشی یا لینک HTTPS صرفاً برای پژوهش**. منطقهٔ زمانی، تایم‌فریم و مشخصات نماد وارداتی را خودتان بررسی کنید؛ فایل به چارت زنده/سفارش نمی‌رسد.
- گزارش ۱۸ شاخص در یادگیری و ژورنال: تعداد، برد/باخت، Long/Short، PF، میانگین سود/زیان، Sharpe معاملاتیِ بدون سالانه‌سازی، مدت متوسط و دنباله‌ها و افت سرمایه. برای نمونهٔ ناکافی «—» نمایش داده می‌شود.

## اجرا و تست

```bash
cd android
./gradlew testDebugUnitTest assembleDebug
# ویندوز: gradlew.bat testDebugUnitTest assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

نیاز به JDK 17 و Android SDK 35 داری. فایل `.github/workflows/main.yml` روی PR هم تست‌ها و سپس APKها را می‌سازد. خروجی موسوم به release در CI با **کلید debug** امضا شده و مناسب انتشار عمومی نیست.

**کلید provider را در APK نگذارید.** بعد از نصب، از تب تنظیمات کلید Twelve Data داده‌خوانی را وارد کنید. کلیدهای معاملهٔ Nobitex/MT5 را هرگز به اپ ندهید. `android:allowBackup=false` است؛ کلیدهای خواندنی فعلاً در حافظهٔ خصوصی گوشی هستند (نه Android Keystore)، پس APK محصول تجاری نیست.

اتصال بازار چارت به بک‌اند نیاز ندارد؛ برای **خبر فارسی**، اول بک‌اند HTTPS را با `AURUM_FA_NEWS_RSS_URL` و `AURUM_FA_NEWS_ALLOWED_HOST` راه‌اندازی و نشانی عمومی آن را در تنظیمات اپ ذخیره کن. موبایل به `localhost` لپ‌تاپ متصل نمی‌شود. برای تنظیمات دقیق و فهرست قابلیت‌های ناتمام: [نقشهٔ راه](../docs/ROADMAP_FA.md).

تست‌های JVM در `app/src/test` صداقت موتور، مقایسهٔ منابع، آمار، ورودی CSV و نبود نتیجهٔ ساختگی را بررسی می‌کنند. تست‌های backend مستقل‌اند: `cd backend && pytest -q`.
