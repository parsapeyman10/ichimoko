# ساختار تب‌های اپلیکیشن اندروید Aurum Edge

اپلیکیشن دارای **۴ تب** در نوار پایین است:

1. **خانه (`AurumTab.Home`)** — صفحهٔ کامل خانه (`HomeScreen.kt`)
2. **چارت (`AurumTab.Chart`)** — صفحهٔ کامل چارت TradingView (`ChartScreen.kt`)
3. **ژورنال و ریسک (`AurumTab.Journal`)** — مدیریت ریسک و سرمایه، ماشین‌حساب حجم/لات، رصد خودکار قیمت لحظه‌ای تا برخورد به TP یا SL، و تقویم ماهانهٔ سود و زیان بر اساس روز (`JournalRiskScreen.kt`)
4. **بروزرسانی (`AurumTab.Update`)** — صفحهٔ کامل بروزرسانی درون‌برنامه‌ای (`UpdateScreen.kt`)
