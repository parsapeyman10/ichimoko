# اتصال رسمی Gemini و حذف محدودیت فهرست دستی

## قرارداد API

مرجع پیاده‌سازی، صفحات رسمی Google است:

- [API و احراز هویت](https://ai.google.dev/api)
- [generateContent و قرارداد پاسخ](https://ai.google.dev/api/generate-content)
- [فهرست مدل‌ها و صفحه‌بندی](https://ai.google.dev/api/models)
- [خروجی JSON](https://ai.google.dev/gemini-api/docs/generate-content/structured-output)

پیش‌تنظیم **Gemini** اکنون قالب `GEMINI` و پایهٔ `https://generativelanguage.googleapis.com/v1beta` را انتخاب می‌کند، نه مسیر OpenAI-compatible. اتصال‌های دیگر مثل LLMsRelay همچنان قالب قبلی خود را دارند.

- احراز هویت: فقط هدر `x-goog-api-key`. کلید در query string، prompt، خروجی تشخیصی یا APK قرار نمی‌گیرد.
- فهرست: `GET /v1beta/models?pageSize=100` با دنبال‌کردن `nextPageToken`، حذف موارد تکراری و انتخاب مدل‌های دارای `generateContent` در `supportedGenerationMethods`. شناسه‌ها حدس زده نمی‌شوند. برای جلوگیری از حلقه، توکن تکراری یا بیش از ۲۰ صفحه خطاست؛ فهرست ناقص به‌جای فهرست کامل اعلام نمی‌شود.
- تولید: `POST /v1beta/models/{model}:generateContent` با `systemInstruction`، `contents[].parts[].text` و `generationConfig`. پیشوند `models/` فقط یک بار مدیریت و شناسه پیش از درخواست اعتبارسنجی می‌شود.
- تحلیل ساختاریافته: `generationConfig.responseMimeType = application/json`. اعتبارسنجی JSON و قواعد کسب‌وکار قبلی همچنان لازم‌اند؛ هیچ fallback پرداختی که بعد از خطای 400 حالت JSON را حذف کند وجود ندارد.
- پاسخ: متن بخش‌های قابل‌نمایش اولین candidate با وضعیت `STOP` خوانده می‌شود؛ بخش‌های `thought` وارد تحلیل/نمایش نمی‌شوند. پاسخ مسدود، ناقص، `MAX_TOKENS`، ادامه‌دار یا بدون متن نه موفقیت اتصال/تحلیل است و نه مجوز ورود.
- سقف خروجی بین ۴۰۹۶ و ۸۱۹۲ توکن محدود می‌شود تا آزمون قدیمی ۱۶توکنی پیش از پاسخ مدل‌های thinking تمام نشود. این سقف مصرف اجباری نیست؛ مدل همچنان ممکن است به سقف برسد که در آن صورت پاسخ رد می‌شود. پارامتر thinking یا sampling حدسی بر اساس نام مدل ارسال نمی‌شود. مهلت خواندن/کل درخواست Gemini حداکثر ۹۰ ثانیه است.
- redirect برای این مسیر غیرفعال است تا `x-goog-api-key` به مقصد دیگری نرود. کلاینت از همان تنظیم پروکسی/TLS اپ استفاده می‌کند؛ خطای HTTP فقط با پیام امن، بدون بازنمایی بدنهٔ ناشر، گزارش می‌شود.

## استفاده روی گوشی

۱. تنظیمات → خبر و AI → **Gemini**.
۲. کلید شخصی Google AI Studio را فقط داخل کادر رمزدار گوشی وارد کنید؛ آن را در چت یا مخزن قرار ندهید.
۳. «دریافت مدل‌های سرویس» را بزنید و مدلی متناسب با تحلیل متنی/JSON انتخاب کنید.
۴. تنظیمات را ذخیره و «تست اتصال به مدل» را اجرا کنید. حضور مدل در فهرست، تضمین سهمیه، دسترسی منطقه‌ای، پشتیبانی JSON یا اعتبار مالی حساب نیست.

آزمون اتصال یک درخواست واقعی مدل است و ممکن است هزینه داشته باشد. پاسخ به ping اثبات توان معامله یا سودآوری نیست. اگر سرور خبر جداگانه تنظیم شده باشد، همانند قبل در بخش خبر اولویت دارد؛ رابط این موضوع را صریح نشان می‌دهد. برای خبر مستقیم Gemini نشانی سرور خبر را خالی و ذخیره کنید؛ هیچ تنظیم کاربر بی‌اجازه حذف نمی‌شود.

پیش‌تنظیم ذخیره‌شدهٔ رسمی Google OpenAI-compatible به مسیر بومی مهاجرت می‌کند و کلید/مدل موجود حفظ می‌شوند. این هم‌ارزی فقط برای دامنه و مسیر رسمی شناخته‌شده است؛ کلید سرویس دیگر یا میزبان مشابه خودکار منتقل نمی‌شود. ویرایش خالی کلید روی همان تنظیم، کلید قبلی را نگه می‌دارد.

Gemini ابری است و بدون API key کاربر یا بدون ارسال درخواست به Google کار نمی‌کند. این تغییر اطلاعات شخصی، telemetry، فایل یا آپلود ژورنال جدیدی اضافه نمی‌کند؛ ورودی‌های موجود تحلیل بازار/خبر و بررسی معاملات کاغذی طبق همان قابلیت فعال به سرویس انتخاب‌شده ارسال می‌شوند. اپ کلید کاربر را در فضای خصوصی تنظیمات گوشی نگه می‌دارد، نه در کد قابل توزیع. نگهداری/مصرف داده در سرویس تابع شرایط Google است؛ «عدم تبادل هیچ داده‌ای با سرویس» ادعا نمی‌شود.

## همهٔ نمادها، بدون کادر واچ‌لیست

کادر ورود نماد، دکمهٔ ذخیره و انتخابگر محدودِ کنار تنظیم روند/رنج/ترکیبی حذف شده‌اند. `AppSettings.activeSymbols` همیشه کل `WatchCatalog.scannerSymbols` را برمی‌گرداند: **۲۰۰ کریپتو + ۲۵ فارکس + ۵ کالا**. تنظیم قدیمی `v1_watchlist` در حافظهٔ کاربر پاک نمی‌شود، ولی دیگر دامنهٔ اجرا را محدود نمی‌کند.

اسکن، اجازهٔ بررسی کاتالوگ و اعلان‌ها از همین فهرست مشترک استفاده می‌کنند؛ انتخاب نماد نمایشگر دامنهٔ تحلیل را محدود نمی‌کند. `strategyFor(symbol)` حالت دستهٔ آن نماد را به موتور مشترک می‌دهد. استراتژی ثابت فشردگی/انفجار کریپتو، روشن/خاموش‌بودن معاملهٔ خودکار، بررسی دادهٔ مستقل تازه و سقف‌های ریسک تغییر نکرده‌اند. دامنهٔ کامل به معنی مجوز معامله روی دادهٔ ناموجود یا سفارش واقعی نیست.

## آزمون

تست‌های مستقل، مسیر/هدر/بدنهٔ native، مدل‌های صفحه‌بندی‌شده، خطاهای HTTP و نبود retry پنهانی، پاسخ thought/مسدود/ناقص، مهاجرت امن کلید و بی‌اثر بودن واچ‌لیست قدیمی را پوشش می‌دهند. تست‌ها از کلید مصنوعی و پاسخ کنترل‌شده استفاده می‌کنند، نه کلید واقعی کاربر. تأیید اتصال واقعی Google، سهمیه و عملکرد شبکه/Tor به تست همان گوشی با کلید خود کاربر نیاز دارد.
