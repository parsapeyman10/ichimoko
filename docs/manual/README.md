# دفترچهٔ راهنمای فارسی Aurum Edge

این پوشه منبع دفترچهٔ PDF فارسی برنامه است. خروجی نهایی:

```
docs/AurumEdge-Manual-FA.pdf   (A4، ۲۴ صفحه، راست‌به‌چپ)
```

## چطور دوباره ساخته می‌شود

```bash
python3 docs/manual/build_manual.py
```

اسکریپت خودش سه کار را انجام می‌دهد:

1. `build_font.py` را صدا می‌زند و قلم یکپارچه را می‌سازد.
2. محتوا را دو بار رندر می‌کند تا شمارهٔ صفحهٔ هر سرفصل در فهرست درست بنشیند.
3. PDF را در `docs/` می‌نویسد.

پیش‌نیازها (بدون نیاز به Pango/Chromium/WeasyPrint):

```bash
pip install --break-system-packages fpdf2 uharfbuzz fonttools brotli
```

## چرا این‌طور ساخته شده

محیط ساخت، Pango و Chromium ندارد؛ پس شکل‌دهی حروف فارسی و چیدمان راست‌به‌چپ با
fpdf2 و HarfBuzz انجام می‌شود (`set_text_shaping(True)`).

یک نکتهٔ مهم: اگر متن یک خانهٔ جدول از **چند قلم** بیاید (قلم اصلی + قلم جایگزین)،
fpdf2 متن را تکه می‌کند و شمارهٔ گلیف‌ها به هم می‌ریزد و متن روی هم می‌افتد. برای
همین `build_font.py` همهٔ نویسه‌های لازم (فارسی، لاتین، نماد، ایموجی) را در **یک
قلم** جمع می‌کند: `AurumText.ttf`. این فایل بازتولیدپذیر است و در گیت نگه داشته
نمی‌شود.

قلم‌های پایه:

| فایل | کاربرد |
|---|---|
| `Vazirmatn-400.ttf` | حروف فارسی (زیرمجموعهٔ عربی بستهٔ `@fontsource/vazirmatn`) |
| `NotoEmoji-400.ttf` | ایموجی‌های پیام‌های برنامه (ساخته‌شده از `@fontsource/noto-emoji`) |

## ساختار محتوا

| فایل | بخش‌ها |
|---|---|
| `content_p1.py` | جلد، فهرست، شروع سریع، نقشهٔ هشت تب، خانه، رادار (۱۹ استراتژی)، چارت |
| `content_p2.py` | بک‌تست (داده، ماه‌به‌ماه، هزینه، قاعدهٔ ۱٫۵R) و ژورنال |
| `content_p3.py` | هوش عصبی، تنظیمات، پس‌زمینه، آپدیت، داده روی گوشی، عیب‌یابی، فرهنگ پیام‌ها، پرسش‌ها، واژه‌نامه، تاریخچه، پشت جلد |

هر عددی که در دفترچه آمده، از اجرای واقعی روی دادهٔ واقعی (XAU/USD ۱۵دقیقه،
۴۳٬۸۱۰ کندل، ژانویه ۲۰۲۵ تا نوامبر ۲۰۲۶) گرفته شده است.
