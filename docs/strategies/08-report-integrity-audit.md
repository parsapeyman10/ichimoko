# ۰۸ — ممیزی گزارش AI/عصبی: هر عددی که چاپ می‌شود، محاسبه شده است

این سند پاسخ به ممیزی گزارش `AurumEdge_AI_Neural_Full_Report_20261114_013322.pdf` است.
جملهٔ کلیدی ممیزی درست بود:

> «R² = 0.00 ولی t-stat تا −۱۴۵٫۶ — تناقض آماری.»

تناقض نبود؛ **آن t-statها هرگز محاسبه نمی‌شدند.** در کد، به‌ازای هر پارامتر یک عدد دستی
نوشته شده بود. این سند می‌گوید چه چیزی عوض شد و چه چیزی هنوز باز است.

## ۲) قاعدهٔ تازه: پارامتر بی‌مدرک اعمال نمی‌شود

پیش‌ازاین `runParameterRegression` خروجی رگرسیون را **بی‌قید** روی موتور می‌نشست، حتی وقتی
`R² ≈ 0` بود. حالا سه شرط باید هم‌زمان برقرار باشد:

1. نمونه ≥ ۳۰
2. `R² > 0.02`
3. `|t| ≥ ۱٫۹۶` برای همان ضریب

وگرنه **مقدار پیشین** می‌ماند و گزارش سه چیز را نشان می‌دهد: `applied=false`، دلیل متنی
(`significanceNoteFa`)، و یک قضاوت کلی (`fitQualityVerdictFa`). یعنی روی دادهٔ نویزی، برنامه
دیگر «تنظیم الکی» نمی‌کند و در UI هم توست می‌گوید «هیچ پارامتری معنادار نبود».

## ۳) باگ پنهانی که همین تغییر لو داد

با `NaN` شدن R² (حالت «نمونه ناکافی»)، آزمون‌های حافظهٔ شبکه شکستند و معلوم شد:

> `kotlinx.serialization` به‌طور پیش‌فرض روی `NaN` **استثنا** می‌دهد و `persistState` آن را
> بی‌صدا می‌بلعید ⇒ **حافظهٔ شبکه ذخیره نمی‌شد.**

یعنی هر `R²` نامعلوم می‌توانست کل حافظهٔ یادگیری را از بین ببرد. سه `Json` (موتور، دفتر،
دستیار) با `allowSpecialFloatingPointValues = true` تنظیم شدند و آزمون‌ها قفلش می‌کنند.

## ۴) آزمون‌ها

`NeuralRegressionHonestyTest`:

| تست | قفل |
|---|---|
| `empty memory never claims a significant parameter` | بی‌داده: صفر پارامتر اعمال‌شده، همه ردیف‌ها = پیشین، `R² = NaN` |
| `applied parameters always carry a real t-statistic` | اعمال‌شده ⇒ `|t| ≥ ۱٫۹۶` و `SE > 0`؛ هیچ‌کدام از tهای دستی قبلی برنمی‌گردد |
| `one strategy never tunes another strategy` | نمونهٔ BASE، رگرسیون PATEL ⇒ `samplesCount = 0` |
| `confidence intervals stay inside the locked corridor` | R:R ≥ ۱٫۵ و سقف کیجون ≤ ۲٫۲ |

`RiskAndCalendarEngineTest` هم دیگر «R² باید در [۰,۱) باشد» نمی‌خواهد؛ قرارداد جدید
«عدد محاسبه‌شده یا صریحاً نامعلوم» است.
