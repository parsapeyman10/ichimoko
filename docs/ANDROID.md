# ساخت اپ اندروید (APK) — AurumEdge

اپ اندروید این پروژه یک اپ **Kotlin + Jetpack Compose** است که در پوشه `android/` قرار دارد و
فقط با **دیتای واقعی** کار می‌کند. هیچ کندل یا قیمت ساختگی در اپ وجود ندارد؛ اگر اینترنت یا کلید
Twelve Data نباشد، اپ وضعیت «آفلاین / بدون کلید» را نشان می‌دهد و آخرین کندل‌های واقعیِ کش‌شده را
با برچسب «داده کش‌شده» نمایش می‌دهد.

---

## ۱) فعال کردن ساخت خودکار APK (یک‌بار برای همیشه)

فایل workflow از قبل در همین مخزن آماده است:

```
.github/workflows/android.yml
```

محدودیت: توکن‌های رباتیک GitHub اجازهٔ push کردن فایل‌های داخل `.github/workflows/` را ندارند،
پس این یک فایل را باید خودت اضافه کنی. سه راه ساده:

**راه اول — از رابط وب GitHub (ساده‌ترین):**
1. برو به `https://github.com/parsapeyman10/ichimoko`
2. روی شاخهٔ `arena/01a09520-ichimoko` (یا بعد از merge، `main`) فایل
   `.github/workflows/android.yml` را بساز: `Add file → Create new file`
3. محتوای فایل را از همین پروژه کپی کن (فایلش اینجاست، بازش کن و کل محتوا را paste کن) و
   `Commit changes` را بزن.

**راه دوم — با گیت روی کامپیوتر خودت:**
```bash
git checkout main && git pull
# فایل .github/workflows/android.yml را در پروژه کپی کن (از همین ریپو)
git add .github/workflows/android.yml
git commit -m "ci(android): build APK"
git push
```

**راه سوم — از طریق تنظیمات دسترسی:** اگر به ربات Arena دسترسی `workflows` بدهی، دفعهٔ بعد
خودم فایل را push می‌کنم.

## ۲) کلید Twelve Data (اختیاری ولی توصیه‌شده)

- در گیت‌هاب: `Settings → Secrets and variables → Actions → New repository secret`
- نام: `TD_API_KEY` — مقدار: کلید رایگانت از [twelvedata.com](https://twelvedata.com/pricing)
- اگر این secret را بگذاری، APK با همان کلید ساخته می‌شود و اپ بدون تنظیم اضافه کار می‌کند.
- اگر نگذاری، اپ نصب می‌شود ولی در تب «تنظیمات» باید کلید را دستی وارد کنی (کلید در خودِ گوشی
  ذخیره می‌شود و به هیچ‌جا ارسال نمی‌شود جز Twelve Data).

## ۳) گرفتن APK

1. برو به تب **Actions** در گیت‌هاب.
2. ورک‌فلوی **Android APK** را انتخاب کن → دکمهٔ **Run workflow** (یا فقط یک تغییر در `android/`
   push کن؛ خودکار اجرا می‌شود).
3. بعد از چند دقیقه (بار اول ~۵ دقیقه، بعد از آن سریع‌تر چون Gradle کش می‌شود) روی همان اجرا
   کلیک کن و از پایین صفحه بخش **Artifacts** فایل `aurum-edge-apk` را دانلود کن.
4. فایل zip شامل دو APK است:
   - `app-debug.apk` — نسخهٔ دیباگ (نام پکیج `com.aurum.edge.debug`، کنار نسخهٔ اصلی نصب می‌شود)
   - `app-release.apk` — نسخهٔ اصلی؛ با کلید دیباگ امضا شده تا روی گوشی نصب شود
     (`applicationId = com.aurum.edge`).

## ۴) نصب روی گوشی

1. فایل APK را به گوشی منتقل کن (تلگرام/بلوتوث/کابل/Google Drive).
2. در اندروید ۸+ اجازهٔ «نصب از منبع ناشناس» را برای همان اپ (مثلاً Files یا Telegram) فعال کن.
3. اگر Play Protect هشدار داد، گزینهٔ «نصب کن» / `Install anyway` را بزن — علتش این است که APK با
   کلید دیباگ امضا شده و از Play Store نیامده.

## ۵) اگر ورک‌فلو خطا داد چه کنم؟

| خطا | راه‌حل |
|---|---|
| `gradle: command not found` | در ورک‌فلو `gradle/actions/setup-gradle@v4` با `gradle-version: '8.9'` استفاده شده؛ مطمئن شو فایل کامل کپی شده است. |
| `Could not find com.android.tools.build:gradle` | اتصال runner به `dl.google.com` موقتاً قطع بوده — دوباره `Run workflow` بزن. |
| `SDK location not found` | در runner باید `ANDROID_HOME` تنظیم باشد؛ ورک‌فلوی پیش‌فرض این کار را می‌کند (`android-actions/setup-android`). |
| خطای Kotlin در یک فایل | لاگ همان step را باز کن؛ خط کامپایل را برایم بفرست تا فایل را فیکس کنم. |
| APK آپلود نشد | روی اجرا برو → Artifacts؛ اگر `if-no-files-found: error` خطا داد یعنی بیلد fail شده و لاگ بالاتر مشکل را می‌گوید. |

## ۶) ساختن APK روی کامپیوتر خودت (بدون گیت‌هاب)

اگر Android Studio داری:

```bash
cd android
./gradlew assembleRelease        # ویندوز: gradlew.bat assembleRelease
# خروجی: app/build/outputs/apk/release/app-release.apk
```

کلید Twelve Data برای بیلد محلی:

```bash
# ویندوز (PowerShell)
$env:TD_API_KEY="your-key"; .\gradlew.bat assembleRelease
# لینوکس/مک
TD_API_KEY=your-key ./gradlew assembleRelease
```

## ۷) رفتار اپ در حالت‌های مختلف شبکه (مهم)

| وضعیت | رفتار اپ |
|---|---|
| اینترنت + کلید صحیح | اتصال WebSocket برای تیک‌های واقعی، ۱۵۰۰ کندل واقعی از REST؛ تب‌ها زنده به‌روزرسانی می‌شوند. |
| اینترنت قطع | وضعیت **آفلاین** با متن فارسی؛ فقط آخرین کندل‌های واقعی ذخیره‌شده روی گوشی با برچسب «داده کش‌شده» دیده می‌شود. هیچ کندلی ساخته نمی‌شود. |
| کلید وارد نشده | تب چارت پیام راهنمای وارد کردن کلید را نشان می‌دهد؛ سیگنال و بک‌تست غیرفعال می‌مانند. |
| سهمیهٔ رایگان تمام شده | اپ خطای سهمیه (429) را نشان می‌دهد و منتظر می‌ماند؛ داده‌ای جعل نمی‌شود. |

## ۸) تب‌های اپ

- **چارت** — کندل‌های واقعی با ابر ایچیموکو، VWAP، EMA200، کراس‌هیر، زوم.
- **سیگنال** — همگرایی فیلترها، ورود/حد ضرر/حد سود، و محاسبهٔ صادقانهٔ حجم با حداقل لات بروکر.
- **یادگیری** — بک‌تست روی همان کندل‌های واقعی (۵۰۰ تا ۵۰۰۰ کندل) + نمودار برابری + لیست معاملات.
- **ژورنال** — معاملات کاغذی روی قیمت واقعی؛ تسویهٔ خودکار وقتی قیمت واقعی به حد ضرر/سود برسد.
- **تنظیمات** — کلید API، نماد، ریسک، موجودی، حداقل اطمینان، مانیتور پس‌زمینه، پاک کردن کش.
