# پشتیبان روزانهٔ رمزگذاری‌شده

در GitHub یک GitHub App اختصاصی بسازید، Device Flow را فعال و Repository permissions → Contents را Read and write انتخاب کنید و آن را فقط روی `parsapeyman10/ichimoko` نصب کنید. شناسهٔ عمومی Client ID را در تنظیمات برنامه وارد و در مرورگر تأیید کنید. Client secret و private key به برنامه یا گفتگو داده نشوند. این مخزن عمومی است؛ محتوا پیش از انتقال با AES-256-GCM و کلید مشتق‌شده از عبارت با PBKDF2-HMAC-SHA256 (۳۱۰٬۰۰۰ دور و نمک تصادفی) رمز می‌شود؛ نام فایل و زمان قابل مشاهده‌اند. عبارت با کلید Android Keystore در گوشی نگهداری می‌شود؛ آن را جداگانه حفظ کنید. عوض کردن عبارت فایل‌های قبلی را تغییر نمی‌دهد.

WorkManager بعد از اتصال بلافاصله و سپس تقریباً هر ۲۴ ساعت هنگام اتصال اینترنت تلاش می‌کند؛ زمان دقیق به اندروید و باتری وابسته است و در force-stop، قطع اینترنت، لغو مجوز یا حذف برنامه تضمین ندارد. وضعیت آخرین تلاش در تنظیمات نشان داده می‌شود. هر گوشی مسیر جدا و هر روز UTC یک فایل دارد؛ تلاش دوباره همان روز نسخهٔ روز را به‌روزرسانی می‌کند. ارسال فقط به شاخهٔ `arena/7db61d5d-ichimoko` انجام می‌شود و پس از بسته‌شدن/حذف شاخه نیاز به پیکربندی تازه دارد. انتشار فایل در شاخه ممکن است CI را فعال کند.

محتوا شامل فهرست ژورنال پس از ادغام شارد، وضعیت کامل شبکه عصبی، تنظیمات ذخیره‌شده به‌جز کلیدها/اعتبارنامه‌ها و حافظه‌های کمکی نام‌برده است؛ اجزا مستقل خوانده می‌شوند و snapshot اتمیک سراسری نیست. کندل‌های خام و فایل‌های بک‌تست جداگانه شامل نشده‌اند. در صورت ناتوانی خواندن یا ارسال، وضعیت خطا ثبت و دوباره تلاش می‌شود. کلید GitHub و عبارت داخل فایل خروجی قرار نمی‌گیرند.

برای خواندن آفلاین: `python -m pip install cryptography` سپس `python tools/decrypt_daily_backup.py backup.json output.json`؛ عبارت فقط در درخواست مخفی برنامه وارد شود، نه در خط فرمان یا گیت. خروجی رمزگشایی‌شده را در گیت عمومی نگذارید.
