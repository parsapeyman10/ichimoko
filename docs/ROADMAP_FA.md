# نقشهٔ ساخت اپ ترید — وضعیت واقعی کد

این مخزن **اپ اندروید بومی + API پژوهشی + وب** است؛ APK موجود روی گوشی کاربر به‌صورت خودکار به‌روز نمی‌شود. نسخهٔ جدید باید ساخته و نصب شود. هیچ ادعای اتصال به حساب واقعی یا سوددهی وجود ندارد.

## راه‌اندازی الان

1. بک‌اند: `cd backend && python -m venv .venv && . .venv/bin/activate && pip install -r requirements.txt && cp .env.example .env && uvicorn app.main:app --host 0.0.0.0 --port 8000`.
2. `.env`: برای چارت وب `AURUM_TWELVE_DATA_API_KEY`؛ برای خبر فارسی **فید دارای مجوز** در `AURUM_FA_NEWS_RSS_URL` و دامنهٔ دقیقش در `AURUM_FA_NEWS_ALLOWED_HOST`. در نبود فید، اخبار خالی و گیت `UNKNOWN` است.
3. اندروید: JDK 17 و Android SDK 35؛ `cd android && ./gradlew testDebugUnitTest assembleDebug`. برای APK تستی، workflow گیت‌هاب فعلاً تست‌های JVM را **بعد از ساخت و غیرمسدودکننده** اجرا می‌کند؛ اصلاح محلیِ ترتیب/سخت‌گیری workflow به مجوز `workflows` برای push نیاز دارد، بنابراین گزارش تست را در Actions جداگانه بررسی کن. کلید Twelve Data **در APK کامپایل نمی‌شود**؛ در تنظیمات گوشی وارد می‌شود (فقط داده‌خوانی).
4. در تنظیمات گوشی، کلید Twelve Data چارت را وارد کن؛ در «منابع هر نماد» منابع/کلید خواندنی نماد را تنظیم کن و تب دیده‌بان را باز کن. برای خبر، یک نشانی HTTPS عمومی بک‌اند (`https://api.example.com`) وارد و گزینهٔ توقف ورود کاغذی را فعال کن؛ آدرس `localhost` روی گوشی به کامپیوتر شما اشاره نمی‌کند.
5. در «یادگیری»، CSV با ستون‌های DATE/TIME/OPEN/HIGH/LOW/CLOSE/TICKVOL و UTC offset سرور بروکر را انتخاب یا URL عمومی HTTPS آن را بده. مشخصات ابزار و اصالت داده را دستی بررسی کن.

## قرارداد و امنیت برای مرحلهٔ سفارش واقعی

- **قبل از پیاده‌سازی**: بازار/جفت Nobitex و نوع حساب/نماد و سرور MT5، مشخصات رسمی API و مجوز دسترسی، حجم حداقل/گام/ارزش هر واحد/کارمزد/اسپرد، محدودیت جغرافیایی/حقوقی و سیاست توقف را تعیین کن. هیچ «کلید عمومی» به معنای مجوز سفارش نیست.
- **سرور اجرا جداگانه**: احراز هویت کوتاه‌عمر و تفکیک کاربر، ذخیرهٔ اسرار در KMS، فقط HTTPS، مجوز حساب، سقف زیان روزانه و اندازهٔ سفارش از سمت سرور، قیمت با timestamp مستقل، گیت خبر با تقویم دارای مجوز، idempotency پایدار در DB، ثبت رویداد و بازیابی وضعیت بروکر پس از قطع شبکه. تأیید دستی و kill-switch قابل آزمون ضروری‌اند.
- **پیش از real money**: تست قرارداد آداپتر با sandbox رسمی، paper/shadow حداقل چند هفته، بررسی تضاد قیمت و توقف خبر در شرایط خطا، آزمون «پاسخ سفارش نامعلوم/تلاش مجدد» و حسابرسی. اجرای واقعی نباید با یک env switch یا گزینه در APK روشن شود.
- این نسخهٔ APK با کلید **debug** امضا می‌شود و فقط برای آزمایش است؛ برای توزیع عمومی signing/keystore امن، حساب کاربر، سیاست حریم خصوصی، محدودسازی نرخ، مانیتورینگ و بررسی حقوقی لازم است. کلید خواندنی Twelve Data فعلاً در فضای خصوصی اپ ذخیره می‌شود و نسخه‌پشتیبان اندروید غیرفعال است؛ برای محصول تجاری حتی این کلید باید به Android Keystore یا پروکسی سرور امن منتقل شود.
