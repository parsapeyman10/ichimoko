# نقشهٔ ساخت اپ ترید — وضعیت واقعی کد

این مخزن **اپ اندروید بومی + API پژوهشی + وب** است؛ APK موجود روی گوشی کاربر به‌صورت خودکار به‌روز نمی‌شود. نسخهٔ جدید باید ساخته و نصب شود. هیچ ادعای اتصال به حساب واقعی یا سوددهی وجود ندارد.

## راه‌اندازی الان

1. بک‌اند: `cd backend && python -m venv .venv && . .venv/bin/activate && pip install -r requirements.txt && cp .env.example .env && uvicorn app.main:app --host 0.0.0.0 --port 8000`.
2. `.env`: برای چارت وب `AURUM_TWELVE_DATA_API_KEY`؛ برای غربال رمزارز بهتر است کلید خواندنی Demo CoinGecko را در `AURUM_COINGECKO_DEMO_API_KEY` فقط روی سرور بگذارید (دسترسی Keyless ممکن است محدود شود). اخبار وب از RSS عمومی ناشرانِ فهرست‌شده در [راهنمای بک‌اند](../backend/README.md) است؛ فید سفارشی دارای مجوز `/news/fa` اختیاری و جداگانه تنظیم می‌شود.
3. اندروید: JDK 17 و Android SDK 35؛ `cd android && ./gradlew testDebugUnitTest assembleDebug`. برای APK تستی، در workflow منتشرشده قدمِ جداگانهٔ JVM هنوز غیرمسدودکننده است، اما `assembleRelease` در Gradle به آزمون‌های `testDebugUnitTest` وابسته است؛ آزمون ناموفق مانع آپلود APK می‌شود. اصلاح خودِ workflow به مجوز `workflows` برای push نیاز دارد. کلید Twelve Data **در APK کامپایل نمی‌شود**؛ در تنظیمات گوشی وارد می‌شود (فقط داده‌خوانی).
4. در تنظیمات گوشی، کلید Twelve Data چارت را وارد کن؛ برای قیمت‌ها منابع دیده‌بان را تنظیم کن. برای اخبار وب و غربالگر رمزارز یک نشانی HTTPS عمومی بک‌اند (`https://api.example.com`) وارد کن؛ آدرس `localhost` گوشی به کامپیوتر توسعه اشاره نمی‌کند. اگر مایل بودی گزینهٔ توقف ورود paper بر مبنای خبر را فعال کن؛ با خوراک ناقص/قدیمی، ورود جدید مسدود می‌شود.
5. خطوط طرح Entry/SL/TP چارت **معامله نیستند**؛ در «ژورنال» معاملهٔ بازشده و کاندیدای هشدار در **دو بخش جدا** هستند. برای ورود خودکار کاغذی ۹/۹ (پیش‌فرض خاموش)، سرورِ دارای کلید AI و اجازهٔ صریح پس از بررسی حقوق ناشر را تنظیم کن، سپس در تنظیمات گوشی پایش و سوییچ خودکار را با تأیید روشن کن. نبود مدل/خبر → نه ورود و نه هشدار واجد شرایط؛ هر خروج فقط روی تیک واقعی ثبت می‌شود. برای هشدار حتی بدون ورود خودکار، پایش و اعلان ۹/۹ را روشن و صدای گوشی را انتخاب/تست کن. در تب «معامله» نیز جهت لانگ یا شورت و SL/TP برای paper دستی ممکن است. بخش نوبیتکس عمومی در تب «رمزارز» جدا از غربالگر CoinGecko/Binance است: BTCUSDT/IRT را دریافت/CSV کن، برای BTCUSDT با نرخ ask فقط BUY فرضی Spot باز کن و سرنوشت را در ژورنال **USDT مستقل** ببین؛ BTCIRT به‌علت اختلاف واحد هنوز paper نمی‌شود. راهنمای دقیق: [ALERT_NOBITEX_FA.md](ALERT_NOBITEX_FA.md).
6. برای دادهٔ تاریخی رایگان در «یادگیری» نماد را انتخاب کن، «دریافت داده» و در صورت نیاز «ذخیرهٔ CSV» را بزن. ارزهای EUR/USD و EUR/GBP از ECB و میانگین ماهانهٔ طلا از بانک جهانی بدون کلید می‌آیند؛ برای سهم لینک کلید خواندنی رایگان Twelve Data همان‌جا هست، ولی طلای اسپات روزانه احتمالاً به دسترسی پولی ناشر نیاز دارد. برای متاتریدر هم جداگانه CSV با DATE/TIME/OPEN/HIGH/LOW/CLOSE/TICKVOL و UTC offset سرور بروکر را انتخاب یا URL عمومی HTTPS آن را بده؛ مشخصات و اصالتش را دستی بررسی کن.

## قرارداد و امنیت برای مرحلهٔ سفارش واقعی

- **قبل از پیاده‌سازی**: بازار/جفت Nobitex و نوع حساب/نماد و سرور MT5، مشخصات رسمی API و مجوز دسترسی، حجم حداقل/گام/ارزش هر واحد/کارمزد/اسپرد، محدودیت جغرافیایی/حقوقی و سیاست توقف را تعیین کن. هیچ «کلید عمومی» به معنای مجوز سفارش نیست.
- **سرور اجرا جداگانه**: احراز هویت کوتاه‌عمر و تفکیک کاربر، ذخیرهٔ اسرار در KMS، فقط HTTPS، مجوز حساب، سقف زیان روزانه و اندازهٔ سفارش از سمت سرور، قیمت با timestamp مستقل، گیت خبر با تقویم دارای مجوز، idempotency پایدار در DB، ثبت رویداد و بازیابی وضعیت بروکر پس از قطع شبکه. تأیید دستی و kill-switch قابل آزمون ضروری‌اند.
- **پیش از real money**: تست قرارداد آداپتر با sandbox رسمی، paper/shadow حداقل چند هفته، بررسی تضاد قیمت و توقف خبر در شرایط خطا، آزمون «پاسخ سفارش نامعلوم/تلاش مجدد» و حسابرسی. اجرای واقعی نباید با یک env switch یا گزینه در APK روشن شود.
- این نسخهٔ APK با کلید **debug** امضا می‌شود و فقط برای آزمایش است؛ برای توزیع عمومی signing/keystore امن، حساب کاربر، سیاست حریم خصوصی، محدودسازی نرخ، مانیتورینگ و بررسی حقوقی لازم است. کلید خواندنی Twelve Data فعلاً در فضای خصوصی اپ ذخیره می‌شود و نسخه‌پشتیبان اندروید غیرفعال است؛ برای محصول تجاری حتی این کلید باید به Android Keystore یا پروکسی سرور امن منتقل شود.
