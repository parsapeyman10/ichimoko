# نقشهٔ ساخت اپ ترید — وضعیت واقعی کد

این مخزن **اپ اندروید بومی + API پژوهشی + وب** است؛ صفحهٔ اول اندروید زمان‌بندی باز/بسته‌شدن معمول بازار را نشان می‌دهد و تب «بروزرسانی» می‌تواند نسخهٔ جدید را از داخل اپ بررسی/دانلود و به نصب‌کنندهٔ Android بسپارد. آپدیت روی نصب قبلی فقط وقتی ممکن است که package همان `com.aurum.edge`، `versionCode` بالاتر و امضای APK همان کلید قبلی باشد؛ این بیلد `versionCode=4` / `versionName=1.2.1` دارد؛ برای امضای ثابت از اسکریپت مالک استفاده کنید. هیچ ادعای اتصال به حساب واقعی یا سوددهی وجود ندارد.

> **۲۰۲۶-۰۹-۲۷:** اپ اندروید بازطراحی شد و **فقط فارکس** است: XAU/USD و جفت‌ارزهای اصلی (EUR/USD، GBP/USD، USD/JPY، AUD/USD، USD/CHF، USD/CAD، NZD/USD). فضاهای نوبیتکس، بورس ایران/آگاه و کریپتو به‌طور کامل از کد اندروید حذف شدند. سرویس‌های وب و بک‌اند فعلاً در دامنهٔ این تغییر نیستند.

## راه‌اندازی الان

1. بک‌اند: `cd backend && python -m venv .venv && . .venv/bin/activate && pip install -r requirements.txt && cp .env.example .env && uvicorn app.main:app --host 0.0.0.0 --port 8000`.
2. `.env`: برای چارت وب `AURUM_TWELVE_DATA_API_KEY`. نمایش تیترهای خبر در گوشی از RSS/Atom عمومی ناشرانِ ثابت بدون تنظیم بک‌اند انجام می‌شود؛ گیت/AIِ ورود خبر را بک‌اند به‌طور مستقل از ناشرانِ [راهنمای بک‌اند](../backend/README.md) بررسی می‌کند؛ فید سفارشی دارای مجوز `/news/fa` اختیاری و جداگانه تنظیم می‌شود.
3. اندروید: JDK 17 و Android SDK 35؛ `cd android && ./gradlew testDebugUnitTest assembleDebug`. برای APK تستی، workflow گیت‌هاب `assembleRelease` را با وابستگی به `testDebugUnitTest` اجرا می‌کند؛ آزمون ناموفق مانع آپلود APK می‌شود. release CI با debug key موقت فقط preview است؛ برای آپدیت پایدار روی نسخهٔ قبلی، APK را با همان keystore مالک و اسکریپت محلی بسازید. کلید Twelve Data **در APK کامپایل نمی‌شود**؛ در تنظیمات گوشی وارد می‌شود (فقط داده‌خوانی).
4. در تنظیمات، کلید Twelve Data چارت را وارد کن؛ کلید جداگانهٔ دیده‌بان همان‌جا تنظیم می‌شود. برای دیدن تیترهای وب/تقویم نیازی به سرور نیست؛ برای گیت خبر/AI فارکس نشانی HTTPS بک‌اند را بده (`https://api.example.com`)؛ آدرس `localhost` گوشی به کامپیوتر توسعه اشاره نمی‌کند. اگر مایل بودی گزینهٔ توقف ورود paper بر مبنای خبر را فعال کن؛ با خوراک ناقص/قدیمی، ورود جدید مسدود می‌شود.
5. خطوط طرح Entry/SL/TP چارت **معامله نیستند**؛ در «ژورنال» معاملهٔ بازشده و کاندیدای هشدار در **دو بخش جدا** هستند. برای ورود خودکار کاغذی ۹/۹ (پیش‌فرض خاموش)، سرورِ دارای کلید AI و اجازهٔ صریح پس از بررسی حقوق ناشر را تنظیم کن، سپس در تنظیمات گوشی پایش و سوییچ خودکار را با تأیید روشن کن. نبود مدل/خبر → نه ورود و نه هشدار واجد شرایط؛ هر خروج فقط روی تیک واقعی ثبت می‌شود. برای هشدار حتی بدون ورود خودکار، پایش و اعلان ۹/۹ را روشن و صدای گوشی را انتخاب/تست کن. در تب «معامله» نیز جهت لانگ یا شورت و SL/TP برای paper دستی ممکن است. راهنمای دقیق: [ALERTS_FA.md](ALERTS_FA.md).
6. برای دادهٔ تاریخی رایگان در «یادگیری» نماد را انتخاب کن، «دریافت داده» و در صورت نیاز «ذخیرهٔ CSV» را بزن. ارزهای EUR/USD و EUR/GBP از ECB و میانگین ماهانهٔ طلا از بانک جهانی بدون کلید می‌آیند؛ طلای اسپات روزانه احتمالاً به دسترسی پولی ناشر نیاز دارد. برای متاتریدر یا دیتاست آموزشی هم جداگانه CSV/TSV با `timestamp`/`datetime`/date یا DATE/TIME و OPEN/HIGH/LOW/CLOSE (حجم اختیاری/خالی) و UTC offset دیتاست را انتخاب یا URL عمومی HTTPS آن را بده؛ مشخصات و اصالتش را دستی بررسی کن.

## قرارداد و امنیت برای مرحلهٔ سفارش واقعی

- **قبل از پیاده‌سازی**: بازار/جفت و نوع حساب/نماد و سرور بروکر، مشخصات رسمی API و مجوز دسترسی، حجم حداقل/گام/ارزش هر واحد/کارمزد/اسپرد، محدودیت جغرافیایی/حقوقی و سیاست توقف را تعیین کن. هیچ «کلید عمومی» به معنای مجوز سفارش نیست.
- **سرور اجرا جداگانه**: احراز هویت کوتاه‌عمر و تفکیک کاربر، ذخیرهٔ اسرار در KMS، فقط HTTPS، مجوز حساب، سقف زیان روزانه و اندازهٔ سفارش از سمت سرور، قیمت با timestamp مستقل، گیت خبر با تقویم دارای مجوز، idempotency پایدار در DB، ثبت رویداد و بازیابی وضعیت بروکر پس از قطع شبکه. تأیید دستی و kill-switch قابل آزمون ضروری‌اند.
- **پیش از real money**: تست قرارداد آداپتر با sandbox رسمی، paper/shadow حداقل چند هفته، بررسی تضاد قیمت و توقف خبر در شرایط خطا، آزمون «پاسخ سفارش نامعلوم/تلاش مجدد» و حسابرسی. اجرای واقعی نباید با یک env switch یا گزینه در APK روشن شود.
- این نسخهٔ APK با کلید **debug** امضا می‌شود و فقط برای آزمایش است؛ برای توزیع عمومی signing/keystore امن، حساب کاربر، سیاست حریم خصوصی، محدودسازی نرخ، مانیتورینگ و بررسی حقوقی لازم است. کلید خواندنی Twelve Data فعلاً در فضای خصوصی اپ ذخیره می‌شود و نسخه‌پشتیبان اندروید غیرفعال است؛ برای محصول تجاری حتی این کلید باید به Android Keystore یا پروکسی سرور امن منتقل شود.
